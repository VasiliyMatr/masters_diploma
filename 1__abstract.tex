\section*{Аннотация}

Трасса исполнения представляет собой упорядоченный набор записей о событиях, происходивших в ходе трассировочного запуска приложения \cite{pinplay,whole_execution_traces}. Такие трассы широко применяются в индустрии для решения различных задач, в том числе для анализа производительности платформ \cite{pinplay,autofdo,lisitsyn_disser}. В работе рассматривается задача адаптации трасс исполнения, записанных для RISC-архитектуры, к новой конфигурации системы памяти. Настройки системы памяти трассируемой платформы могут отличаться от настроек целевой платформы, поэтому требуется изменить записанный в трассе образ памяти, сохранив согласованность потоков управления и данных.

Цель работы -- разработать средство для модификации трасс, которое переносит области образа памяти в соответствии с ограничениями новой конфигурации. Решение анализирует граф потока данных для поиска и модификации адресов и смещений в трассе. Описаны алгоритмы для сбора и анализа данного графа, а также симуляционный проход по модифицированной трассе для обработки граничных случаев. Рассмотренный подход позволяет получать консистентные и репрезентативные трассы.

Показано, что временная и пространственная сложности обработки трасс линейны по числу инструкций и зависимостей по данным. Предложены метрики для оценки влияния модификаций на репрезентативность трасс, приведены результаты запусков средства на целевых трассах заказчика для одной конфигурации системы памяти. Решение применяется для анализа поведения разрабатываемой платформы на целевых сценариях исполнения.
