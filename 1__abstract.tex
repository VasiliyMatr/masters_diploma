Трасса исполнения представляет собой набор бинарных или текстовых файлов, содержащих упорядоченные записи о событиях, происходивших в ходе трассировочного запуска целевого приложения \cite{pinplay,whole_execution_traces}. Трассы исполнения широко применяются в индустрии для решения различных задач, таких как: исследование поведения приложений, отладка, сбор профилей исполнения для компиляторов \cite{pinplay,autofdo,lisitsyn_disser}. В рамках данной работы рассмотрены трассы под архитектуру ARM64 \cite{armv8_a_isa}.

Возникает необходимость анализа трасс исполнения, при настройках адресации, отличных от настроек исходной платформы, - платформы, на которой трассы были записаны. Подобный подход может быть использован для оценки производительности еще не выпущенных платформ при различных конфигурациях адресации \cite{nocua_gem5_trace_driven}.

В рамках данной работы описано решение, модифицирующее трассы исполнения для изменения образов памяти записанных сценариев исполнения. Решение позволяет перемещать области исходного образа памяти для удовлетворения ограничений, обусловленных новыми настройками адресации.

Для генерации необходимых модификаций трасс используется граф потока данных. Реализованы алгоритмы для: генерации карты перемещений областей памяти, сбора графа потока данных с трассы исполнения, поиска локаций адресов и смещений на графе, обработки краевых случаев с помощью симуляционного прохода по модифицированной трассе. Описанных подход позволяет существенно снизить влияние модификаций на репрезентативность модифицированных трасс и может быть использован для других задач, связанных с модификацией адресов в трассах исполнения.

Предложенное решение успешно применяется для анализа записанных сценариев исполнения с увеличенными размерами страниц адресации и расширенными областями, зарезервированными под данные ядра операционной системы. Произведена оценка влияния модификаций трасс на их репрезентативность. Предложены возможности для дальнейшего улучшения решения и новые направления для его применения.
