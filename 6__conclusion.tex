\section{Заключение}

Целью работы была разработка решения для модификации записанных в трассах исполнения образов памяти приложений, позволяющего адаптировать трассы для исследования производительности разрабатываемых платформ с новыми настройками системы памяти. Поставленная цель достигнута.

Задача разработки решения была успешно выполнена: разработано представление ГПД, выбраны виды используемых модификаций трассы, построены многопроходные алгоритмы для сбора ГПД трассы и его анализа, реализованы другие вспомогательные компоненты. Области исходного образа памяти перемещаются для удовлетворения новых ограничений. Генерация необходимых модификаций осуществляется на основании анализа ГПД.

Решение было протестировано на наборе целевых трасс заказчика. Выходные трассы были верифицированы с помощью функциональной симуляции. В ходе тестирования были собраны метрики для количественной оценки решения и выходных трасс. Для оценки влияния производимых модификаций на репрезентативность выходных трасс были введены метрики $N_{comp}$ и $P_{comp}$, показывающие, сколько инструкций трассы из-за произведенных модификаций потребуют компенсации при дальнейшей обработке. Таким образом, задачи тестирования решения и оценки влияния модификаций на репрезентативность трасс также успешно выполнены.

Предложенное графовое представление и алгоритмы позволяют находить в потоке данных трассы адреса и смещения, а также контексты их использования. Временная и пространственная сложность обработки трассы линейны по количеству инструкций. Симуляционный проход по трассе с применением модификаций позволяет исправлять расхождения потоков управления и данных, хотя и может сильно снижать репрезентативность выходной трассы. В частности, на данном проходе обрабатываются еще не поддержанные граничные случаи.

В тестовой выборке было 272 трассы, из них 264 (97\%) без ошибок обработаны решением, 217 (80\%) прошли верификацию. 132 (49\%) трассы прошли верификацию и проверку на репрезентативность ($P_{comp} \leq 0.01$) -- данные трассы могут быть использованы для исследования производительности разрабатываемой платформы.

Предложенные метрики для оценки влияния модификаций на репрезентативность трасс собираются во время обработки трассы решением -- полноценный анализ трассы на модели не требуется. Это позволяет быстро находить проблемные сценарии.

Была разработана инфраструктура для описания тестовых сценариев для юнит- и модульных тестов. На основе данной инфраструктуры были написаны базовые тесты для модуля сбора ГПД. Данная инфраструктура может быть применена для покрытия тестами других модулей.

Основным научным вкладом автора является разработка методологии для поиска адресов, смещений и контекстов их использования в потоке данных трассы. Также были предложены уже упомянутые в данном разделе метрики и получены экспериментальные данные для количественной оценки реализации.

Разработанное средство успешно применяется для адаптации трасс исполнения под новую конфигурацию системы памяти. Получаемые трассы используются для исследования поведения разрабатываемой системы. Также разработанные алгоритмы и графовое представление могут быть использованы для решения других задач, связанных с поиском адресов в трассах. Например, для модификации адресов, защищенных аппаратными механизмами контроля целостности (см. раздел \ref{sec:application_crypto}).

К основным ограничениям решения относятся высокое потребление памяти (линейно по количеству инструкций), неполная поддержка граничных случаев и связанная с этим низкая репрезентативность выходных трасс на ряде сценариев. Возможные способы решения этих проблем описаны в разделе \ref{sec:future_work}.
